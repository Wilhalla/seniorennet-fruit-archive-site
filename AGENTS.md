# Agent Instructions

## Commit messages

Use [Conventional Commits 1.0.0](https://www.conventionalcommits.org/en/v1.0.0/) for every commit: `type(scope): summary`, with the scope optional. Use `feat` for features, `fix` for bug fixes, and `!` or a `BREAKING CHANGE:` footer for breaking changes. Other descriptive types such as `docs` and `chore` are allowed. Run `just setup` in a fresh checkout to enable the tracked `commit-msg` hook.
